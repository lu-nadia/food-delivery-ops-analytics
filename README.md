# 🛵 Food Delivery Operations & SLA Analytics

Проект посвящен исследованию операционной эффективности сервиса экспресс-доставки (Quick-Commerce / Uzum Tezkor), поиску «узких мест» (bottlenecks) в логистике и анализу факторов, влияющих на время выполнения заказов и уровень SLA (Service Level Agreement).

## 📌 Бизнес-контекст и цели
* Основная цель: Проанализировать полный цикл исполнения заказа (от создания до вручения клиенту) и выявить ключевые причины задержек.
* Целевой показатель SLA: Доставка в пределах 35 минут.
* Задачи:
  1. Оценить долю заказов с нарушением SLA.
  2. Определить влияние времени суток, плотности трафика и типа транспорта на время доставки.
  3. Рассчитать физическое расстояние логистики по географическим координатам (Haversine Formula).
  4. Сформировать бизнес-рекомендации для операционного отдела.

## Основные выводы и операционные рекомендации

Главная проблема в пиковых часах - наибольший процент задержек фиксируется в промежутках с 18:00 до 21:00 из-за высокой плотности трафика

# Рекомендации
- Перераспределить смены курьеров с приоритетом на вечернее время
- Перевести часть флота в центральных зонах на электроскутеры и велосипеды для снижения чувствительности к пробкам
- Внедрить динамический радиус зоны доставки в часы высокой загруженности
